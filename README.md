# 🌐 Multi-Cloud Storage Sync: AWS S3 and Google Cloud Storage Project

---

## Project Overview  
I built a multi-cloud storage solution that synchronises data between **AWS S3** and **Google Cloud Storage**. This project involved setting up AWS S3 as the primary data source, configuring cross-cloud authentication using IAM roles for identity federation, and implementing batch transfer jobs to move data securely across platforms.

---

## Project Highlights  

### What I Did:  
- 🏗 **Configured AWS S3 as Primary Data Source**: Set up and organised S3 buckets to store data for transfer.  
- 🔐 **Set Up Cross-Cloud Authentication**: Used IAM roles for secure identity federation between AWS and Google Cloud.  
- 🔄 **Implemented Batch Transfer Jobs**: Automated data transfers between AWS and Google Cloud, allowing seamless access to S3 files within Google Cloud.  
- 📊 **Verified Data Synchronisation**: Successfully accessed S3 storage files within Google Cloud, confirming data flow integrity.

---

### Next Phase:  
- 🔒 **Security Enhancements**: Strengthen cross-cloud authentication and encryption protocols for additional security.  
- 📈 **Monitoring & Optimisation**: Implement CloudWatch and Google Cloud's monitoring tools to ensure seamless data transfers.  
- 🛠 **Further Automation**: Automate more cloud storage operations and transfer processes to ensure scalability and efficiency.

---

## Why Multi-Cloud?  
Multi-cloud architectures provide **redundancy**, **flexibility**, and **cost-efficiency** by leveraging multiple cloud platforms. This setup prevents vendor lock-in while optimising performance, offering a scalable and resilient storage solution.
